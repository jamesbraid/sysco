# l2_partition_requests

Request codes of the L2 controller partition task image. Codes are unique within the image.

Source: L2 1.44.0 partition task image (l2part).

The values are in [format.toml](format.toml), each graded and sourced, and the generated reference page is [format.md](format.md).
